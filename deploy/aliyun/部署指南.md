# 把「中俄消防管材合规 Agent」部署到阿里云 ECS

> 目标：让小程序/网页能访问后端，让企业微信推送能跑。核心是部署 `engine/api_server.py`（FastAPI）。
> 本号提供 `deploy/aliyun/` 全套配置：`.env.example`、`systemd/cnru-api.service`、`nginx/cnru-api.conf`、`deploy.sh`。

---

## 0. 整体架构（阿里云 ECS 上跑什么）

```
小程序(企业微信)  ──HTTPS──▶  Nginx(443, 反代) ──▶  gunicorn/uvicorn(127.0.0.1:8000) ──▶  api_server.py
                                      │                                                    │
                                      │                        /api/evaluate 规则引擎(evaluate.py + data/*.json)
                                      │                        /api/report   LLM报告(llm_report.py, 需 LLM_API_KEY)
                                      │                        /api/meta
                                                                   │
                                                                   └─▶ 企业微信推送(push_wechat.py, 需 WC_*; 主动调 qyapi.weixin.qq.com)
```

---

## 1. 前置准备（阿里云上）

| 项 | 说明 |
|---|---|
| **ECS 实例** | 建议 Ubuntu 22.04 / Debian 12，2C2G 起步；安全组只开 **22/80/443** |
| **域名** | 一个已做 **ICP 备案** 的域名（大陆 ECS 80/443 对外提供服务必须备案）|
| **SSL 证书** | 阿里云【数字证书】免费申请，或 `certbot --nginx`；域名解析到 ECS 公网 IP |
| **代码上传** | git clone 或 `scp -r` 到服务器 `/opt/cnru-fire-pipe` |

---

## 2. 部署步骤（Ubuntu/Debian）

### 2.1 系统依赖
```bash
sudo apt update && sudo apt install -y python3 python3-pip python3-venv git nginx rsync
```

### 2.2 拷贝项目（只要运行必需的 engine/ data/ examples/ scripts/）
```bash
sudo mkdir -p /opt/cnru-fire-pipe
sudo rsync -a --exclude __pycache__ ./engine ./data ./examples ./scripts /opt/cnru-fire-pipe/
```

### 2.3 装依赖（虚拟环境）
```bash
cd /opt/cnru-fire-pipe
python3 -m venv .venv
.venv/bin/pip install --upgrade pip
.venv/bin/pip install -r engine/requirements.txt gunicorn
```

### 2.4 配置环境变量
把 `deploy/aliyun/.env.example` 里的值填好，写到 `/etc/cnru-fire-pipe.env` 或直接在 systemd 里 `Environment=`：
- `LLM_PROVIDER`（`mock` 可先跑；`openai` 需 `LLM_API_KEY`/`LLM_MODEL`）
- `WC_CORP_ID` / `WC_AGENT_SECRET` / `WC_AGENT_ID`（企业微信推送）

### 2.5 用 systemd 常驻（自动拉起）
```bash
sudo cp deploy/aliyun/systemd/cnru-api.service /etc/systemd/system/cnru-api.service
sudo systemctl daemon-reload
sudo systemctl enable --now cnru-api
systemctl status cnru-api        # 应显示 active (running)
curl -s http://127.0.0.1:8000/health   # {"status":"ok",...}
```

### 2.6 Nginx 反代 + HTTPS
```bash
sudo cp deploy/aliyun/nginx/cnru-api.conf /etc/nginx/conf.d/cnru-api.conf
# 把 your-domain.com 改成你的域名；把证书放到 /etc/nginx/ssl/ 或走 certbot
sudo nginx -t && sudo systemctl reload nginx
curl -k https://你的域名/health
```

> 备用：也可以直接 `docker build -t cnru-fire-pipe -f engine/Dockerfile .` + 阿里云容器镜像服务 + 负载均衡（但 ECS 裸机更简单）。

## 3. 把小程序连到服务器

1. 改 `miniprogram/app.js`：
   ```js
   apiBase: "https://你的域名"      // 原来 http://127.0.0.1:8000
   ```
2. 微信开发者工具【详情 → 域名信息】配置：
   - **request 合法域名** = `https://你的域名`（必须是 HTTPS、且域名已备案）
   - 开发阶段可勾选"不校验合法域名"快速联调。
3. 小程序里点"开始合规判定"应能拿到结果。

---

## 4. 连微信推送（企业微信）

1. 注册企业微信并认证，创建**自建应用**，拿到 `corpid`、`应用 secret`、`agentid`。
2. 填到环境变量 `WC_CORP_ID` / `WC_AGENT_SECRET` / `WC_AGENT_ID`。
3. `push_wechat.py` 会主动调 `https://qyapi.weixin.qq.com/cgi-bin/message/send`（**出站**，无需回调域名）。
4. 先设 `WECHAT_DRY_RUN=1` 打印负载联调，再取消、用 `--real` 真实下发。
5. 测试：
   ```bash
   cd /opt/cnru-fire-pipe
   .venv/bin/python engine/push_wechat.py --userid 张三 --title "合规评价完成" \
       --content "型号...中国 A / 俄罗斯 C，需强制认证。" --url "https://你的域名/report" --real
   ```

> 公众号（服务号）通道：需要 **HTTPS 回调域名（已备案）+ 一次性订阅消息**，适合外部客户；非必需，可后用。

## 6. 常见坑

| 坑 | 解法 |
|---|---|
| 大陆 ECS 80/443 打不开 | **ICP 备案** + 安全组放行 80/443 |
| 小程序 request 域名报错 | 域名需 **HTTPS + 已备案** 并在小程序后台加白 |
| 微信回复"回调 URL 需 HTTPS" | 公众号回调必须 443 + 备案域名 |
| `/api/evaluate` 报 500 | 看 `systemctl status cnru-api` 日志；多为知识库路径或依赖缺失 |
| 推送报 43101/无效 userid | userid 拼写、是否在应用可见范围；先 `--dry-run` |
| 跨域（CORS） | `api_server.py` 已 `allow_origins=["*"]`，生产可收紧 |
| access_token 过期 | 企业微信 token 约 2 小时，**必须缓存**；MVP 进程内存缓存，正式建议 Redis |

## 7. 备选：微信云托管（免备案）

现有 `engine/Dockerfile` 就是给**微信云托管 CloudBase Run** 用的，**免 ICP 备案**：
```bash
docker build -t cnru-fire-pipe -f engine/Dockerfile .
# 推送到腾讯云镜像仓库 → 云托管服务监听 8000 → 小程序 baseURL 用云托管分配的 https 域名
```
适合不想走备案、只想快速上线的场景。你问的是阿里云，则走上面 2–6 节即可。
